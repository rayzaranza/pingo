# Color Tokens

Pingo comes with a basic color system separated into two layers: primitive and semantic.

## Primitive Colors

Primitive colors are the foundation of Pingo color system. It represents all available tones in 9 steps and all semantic tokens are derived from it.

It's recommended to use primitive colors only when a semantic token doesn't work for your use case.
